# squadra

**Your app's style as 8 settings: read from your code, enforced on your agent.**

> Pre-alpha, built in public. Nothing here is usable yet. See [github.com/piotr-g9k/squadra](https://github.com/piotr-g9k/squadra) for the plan and roadmap.

Squadra describes a Tailwind v4 app's style as 8 settings in DESIGN.md (fill, edges, shadow, color, shape, density, type, motion), and those settings switch on lint rules your coding agent is fed back after every edit.
